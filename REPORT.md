## 2. Відповідь на контрольне запитання

**Запитання:** `Що таке «жадібні» та «ліниві» квантифікатори в регулярних виразах?`

**Відповідь:**

`Жадібні (greedy) квантифікатори — *, +, ?, {n,m} - діють за замовчуванням: захоплюють якомога довшу послідовність символів. Якщо після цього решта патерну не збігається, вони віддають частину символів назад.`

`Ліниві (lazy, non-greedy) квантифікатори - *?, +?, ??, {n,m}? (жадібний квантифікатор із додатковим знаком ?) - навпаки, захоплюють якомога коротшу послідовність.`

Приклади:

```python
import re

s = '<b>one</b><b>two</b>'
re.findall(r'<b>.*</b>', s)    # ['<b>one</b><b>two</b>']      жадібний: від першого <b> до останнього </b>
re.findall(r'<b>.*?</b>', s)   # ['<b>one</b>', '<b>two</b>']  лінивий: кожен тег окремо

re.search(r'\d{2,4}',  '123456').group()   # '1234' - максимум цифр
re.search(r'\d{2,4}?', '123456').group()   # '12'   - мінімум цифр

re.findall(r'"(.*)"',  '"a" i "b"')   # ['a" i "b']  жадібний захопив зайве
re.findall(r'"(.*?)"', '"a" i "b"')   # ['a', 'b']   лінивий дав очікуваний результат
```

`Ліниві квантифікатори потрібні, коли між двома обмежувачами (лапки, теги, дужки) треба знайти найближчу пару, а не найдовший фрагмент. Жадібні підходять, коли потрібно захопити весь можливий фрагмент, наприклад усе число через \d+.`

`У цій роботі у патерні неоптахи\s+([A-Z]{2}-\d+) квантифікатор \d+ жадібний, тому для NB-201 він захоплює всі три цифри. Лінивий \d+? повернув би лише NB-2.`
