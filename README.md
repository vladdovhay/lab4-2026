# Лабораторна робота № 4. Обробка рядків та регулярні вирази

## Мета роботи

Поглибити розуміння роботи з рядками в Python, освоїти методи форматування рядків та навчитися ефективно використовувати регулярні вирази для обробки текстової інформації.

## Структура репозиторію

- [`README.md`](./README.md) – цей файл, що містить опис лабораторної роботи та варіанти завдань.
- [`REPORT.md`](./REPORT.md) – шаблон звіту, який необхідно заповнити за результатами виконання роботи.
- [`src/lab4.py`](src/lab4.py) – основний файл для вашого коду.
- [`src/data/neoterra_text.txt`](src/data/neoterra_text.txt) – файл, що містить текст для аналізу.
- [`tests/test_lab4.py`](tests/test_lab4.py) – файл для написання тестів до вашого коду.

## Завдання для всіх варіантів

1.  **Розробка функцій для обробки рядків.**
    -   Створіть функції для виконання базових операцій з рядками (наприклад, пошук підрядка, заміна, розділення).
    -   Реалізуйте функції для форматування рядків з використанням f-strings та методу `.format()`.

2.  **Реалізація регулярних виразів.**
    -   Напишіть функції для пошуку та виділення певних патернів у тексті за допомогою регулярних виразів.
    -   Створіть функції для валідації введених користувачем даних (наприклад, email, телефонний номер) з використанням регулярних виразів.

3.  **Обробка текстових даних.**
    -   Розробіть програму для аналізу текстового файлу [`src/data/neoterra_text.txt`](src/data/neoterra_text.txt), яка виконує підрахунок слів, речень, частоти слів тощо.
    -   Реалізуйте функції для виведення результатів у зручному форматі.

4.  **Тестування та обробка помилок.**
    -   Додайте обробку винятків для захисту від некоректного введення даних.
    -   Створіть набір тестів у файлі [`tests/test_lab4.py`](tests/test_lab4.py) для перевірки правильності роботи ваших функцій.

5.  **Вилучення інформації за допомогою регулярних виразів.**
